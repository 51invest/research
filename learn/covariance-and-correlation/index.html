协方差与相关性

协方差和相关系数描述两个变量的线性共同变动；它们不识别因果，也不能替代对样本、时间对齐和异常值的检查。

研究问题

两个变量一起变动，意味着什么？如果失业率上升时通胀下降，是否说明失业导致通胀变化？本文明确定义协方差与相关系数，说明它们能回答什么、不能回答什么，并用一个小样本演示计算。结论只适用于该样本的描述，不构成因果或预测。

数据

使用五个观察值（纯教学数据，不是真实统计序列）：

观察 x y
1 1 2
2 2 4
3 3 5
4 4 4
5 5 5

要求：x、y 按同一观察单位对齐；没有缺失；样本量仅为演示。若这是时间序列，还必须先确认频率、共同区间、季调口径和修订版本，不能把不同口径的序列直接配对。

在计算相关或回归之前先看散点图，检查关系形状与异常点，这是 OpenStax 建议的步骤[2]。

方法与公式

样本协方差衡量两个变量偏离各自均值的共同方向：

cov(x, y) = Σ[(x_i - x̄)(y_i - ȳ)] / (n - 1)

样本标准差为：

s_x = √[Σ (x_i - x̄)² / (n - 1)]

协方差的单位是两个变量单位的乘积（例如“百分点 × 百分点”），数值大小依赖量纲，不便跨组比较；相关系数把协方差标准化，消除单位和量纲：

r = cov(x, y) / (s_x × s_y)

r 的范围是 -1 到 1。符号表示线性方向，绝对值表示线性关联的强度；r = 0 只表示没有线性关联，不代表两个变量独立。分母使用 n - 1 还是 n 会改变协方差和标准差的数值（本文样本上协方差由 1.5 变为 1.2，标准差同向变化），但不会改变相关系数：两条路径都给出 r = 0.7746，因为分子分母同时缩放；报告时仍必须说明口径。这一不变性是本文按自身算例复算的结果，不是引用外部结论。

相关系数 r 衡量 x 与 y 之间线性关系的强度与方向，检验的原假设是总体相关系数为零——OpenStax 的口径[1]。

结果

均值为 x̄ = 3，ȳ = 4。离差和乘积如下：

x y x - x̄ y - ȳ 乘积
1 2 -2 -2 4
2 4 -1 0 0
3 5 0 1 0
4 4 1 0 0
5 5 2 1 2
合计 0 0 6

因此：

  • 样本协方差 cov = 6 / 4 = 1.5；
  • s_x = √(10 / 4) ≈ 1.5811；
  • s_y = √(6 / 4) ≈ 1.2247；
  • 相关系数 r = 1.5 / (1.5811 × 1.2247) ≈ 0.7746。

在这个五观察值样本中，x 与 y 呈正线性关联，强度中等偏高。这个数字不是总体相关系数的可靠估计，也不能说明 x 的变化导致 y 的变化。

样本协方差的公式为离差乘积之和除以 n−1，本文的 cov = 6 / 4 就是这条式子的代入（NIST/SEMATECH 手册）[3]。

稳健性与失败条件

  • 样本量过小。 五个点很容易被一个观察值改变；不能据此估计总体关系。时间序列滚动相关应报告窗口长度和有效配对数量；本站正式图表在少于 12 个有效配对时不显示系数。
  • 异常值。 单个极端值可能显著改变协方差和相关系数；应先检查原始序列和测量口径，而不是自动删除。
  • 非线性。 r 只衡量线性关系。明显的 U 形关系可能得到接近零的相关系数，但两个变量并非独立。
  • 取值范围受限。 只观察一小段区间可能压低相关性，不能外推到完整范围。
  • 共同样本与频率。 两个序列必须有相同的观察期和频率；不同频率、缺失和修订会造成伪配对。
  • 时间趋势与伪相关。 两个都随时间上升的序列可能高度相关，但没有直接机制；需要去趋势、差分或明确研究设计。
  • 选择与混杂。 样本如何进入、遗漏了哪些变量、是否存在共同原因，都会影响解释。
  • 多重尝试。 反复尝试不同区间、变换和指标后只报告最强结果，会高估证据强度。

局限

本样本只有五个观察值，且是人为构造的教学数据；没有抽样设计，没有总体推断，也没有控制任何混杂因素。相关分析不能回答因果方向，不能预测未来，也不能说明关系的稳定性。若要研究现实问题，需要明确数据来源、样本期、频率、缺失处理和研究设计，并报告替代口径与失败结果。

复现

  1. 对齐观察值和单位，检查缺失与异常。
  2. 计算均值、离差、离差乘积和。
  3. 选择 n - 1 或 n 作为分母，并在结果中注明。
  4. 计算协方差、两个标准差和相关系数。
  5. 画散点图，检查非线性、异常值和取值范围。
  6. 报告样本量、有效配对、期间和任何变换；不要只报一个 r。

伪代码：

mx = mean(x)
my = mean(y)
cov = sum((x[i] - mx) * (y[i] - my)) / (n - 1)
r = cov / (sd(x, n - 1) * sd(y, n - 1))

结论强度

这里可以陈述的是：在这五个教学观察值中，x 与 y 存在正线性关联（r ≈ 0.7746）。不能陈述总体相关、因果关系、预测能力或统计显著性；显著性检验需要满足相应假设，且不能弥补样本设计或识别问题。

工作纸：把“协方差与相关性”拆成四栏

本文的主题是“协方差与相关性”。读完之后，不要先记结论，先做一张四栏工作纸：第一栏写“协方差”的定义、分子、分母和单位；第二栏写“相关系数”的传导渠道；第三栏写“散点图”的制度边界；第四栏写结论的反证信号。四栏都填满，才允许把结论带进下一步；任何一栏空白，结论就只能当作假设。

第一栏最容易偷懒。把指标写成一句“越高越好”，等于没有定义。至少要回答：它衡量的是存量还是流量，分母是产出、人口、资产还是交易量，价格是名义还是实际，时间点是期末还是期间平均。换掉其中任何一个，排序和结论都可能改变。若来源只给了一个数字而没有给出分母，先回到来源脚注，不要用相邻文章的分母替代。

第二栏要把“相关系数”写成一条可观察的链：哪一个变量先动，经过什么中介，最后改变哪个结果。链上每一环都要有时间和单位，不能把“长期”与“季度”混写。链越长，越要标出哪一环是作者推演、哪一环有来源支持；推演可以用于教学，但不能冒充事实。

第三栏处理制度。散点图不是背景段落，而是样本定义：哪些主体被覆盖，哪些被豁免，规则从哪一天生效，跨境比较是否由同一套规则约束。制度不同，同样的数字会对应不同的激励；把制度差异写成行为差异，是跨市场比较里最常见的错误。若无法确认规则一致，就把比较降级为“两个独立情景”，不要给出排序。

第四栏写反证。用一句可证伪的话收尾：“如果观察到 A，在 B 时间内出现 C，则原判断成立；否则放弃。”A 必须是可观察的变量，B 必须是可以等待的时间，C 必须是可以复核的结果。三项写不清，说明结论还不可检验。最后把工作纸、来源链接和复核日期放在同一页；下一次复盘时，先看当时的四栏，而不是只看事后结果。

练习

  1. 退化情形。 如果所有 y 值都相同，协方差是多少？相关系数能否计算？
  2. 非线性。 令 x = -2, -1, 0, 1, 2，y = x²。y 明显依赖 x，相关系数大约是多少？这说明了什么？
  3. 因果判断。 观察到冰淇淋销量与溺水人数正相关，能否说明冰淇淋导致溺水？还需要考虑哪些解释？
参考答案
  1. 所有 y 相同，y_i - ȳ = 0，协方差为 0；同时 s_y = 0，相关系数的分母为零，因此 r 无定义。应报告“无法计算”，而不是报 0。
  2. 由于 x 的均值为 0、y 的均值为 2，离差乘积之和为 0，协方差为 0，相关系数为 0。尽管 y 完全由 x 决定，线性相关系数仍为零；这提示必须先看散点图和非线性关系。
  3. 不能。常见解释包括天气或季节这一共同原因、人们在水边活动增加、样本选择和报告偏差等；相关本身不能区分这些机制，需要额外识别策略。
  1. 用 100 字说明“RES-010”里的核心指标，必须写出分母和单位。
  2. 把“协方差”与“相关系数”各写成一个可观察变量，并指出二者的时间差。
  3. 给“散点图”找一个规则变化，说明它如何改变样本覆盖。
  4. 用本文的方法做一次反事实：只改变一个变量，其他条件保持不变。
  5. 如果换一个独立来源，哪一个数量级最可能变化？为什么？
  6. 写一条可证伪判断，包含观察信号、等待时间和复核指标。
