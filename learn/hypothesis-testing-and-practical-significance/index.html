假设检验与实际意义

假设检验把“没有差异”作为原假设，用样本判断证据是否足够拒绝它；p 值小只说明与零假设不一致，不等于效应大、重要或真实。

模块RES-M03 · 统计推断
层级入门
阅读4 分钟 · 12 节

这篇有一个可以动手操作的演示 ↓

研究问题

一个假设的 36 个月样本：月均收益 1.20%，样本标准差 2.40%。策略是否产生了高于零的平均收益？如果事前设定的最低经济要求是每月 0.60%，同一组数据能否支持“达到实际意义”？本文区分统计显著与实际意义，说明 p 值、显著性水平和两类错误。数值为教学假设。

数据

项目 数值
样本量 n 36
样本均值 1.20% / 月
样本标准差 2.40 百分点
标准误 0.40 百分点
原假设 H0 μ = 0
备择假设 Ha μ ≠ 0
实际意义门槛（事前设定） 0.60% / 月

样本为假设的简单随机样本；门槛在看数据前设定，避免事后挑选标准。

方法与假设

检验统计量：

t = (x̄ - μ0) / (s / √n)

在 H0 下，t 服从自由度 n-1 的 t 分布。取双侧检验，α = 0.05；若 |t| 超过 t(0.975, 35) = 2.030，或 p < 0.05，则拒绝 H0（OpenStax 9.1、9.5）。α 是 H0 为真时错误拒绝的概率；β 是 H0 为假时未能拒绝的概率，随真实差异变小而上升（OpenStax 9.2；NIST 7.1.3 指出小差异更难发现，且 α 降低时 β 上升）。检验功效（power）是 H0 为假时正确拒绝的概率，OpenStax 记作 1−β（OpenStax 9.2）；它与前一句构成一对：显著性水平管的是误报率，功效管的是在给定样本量下真差异被发现的概率。因此本文的 0.60% 实际门槛必须在事前设定：门槛越接近 0，同样的 n=36 越难把功效提上来，只能靠增大样本或改进设计。关键假设：简单随机样本、观察独立、均值抽样分布近似正态、μ0 和门槛事先确定。

结果

SE = 2.40/√36 = 0.40。

t = (1.20 - 0)/0.40 = 3.00，df = 35。

双侧 p ≈ 0.005；95% 区间为 0.39% 至 2.01%，不含 0。按 α = 0.05 拒绝 H0，数据与“月均收益为零”不一致。

但门槛是 0.60%：单侧检验 t = (1.20 - 0.60)/0.40 = 1.50，p ≈ 0.071；在 5% 水平不能拒绝 μ ≤ 0.60%。也就是说，统计上能与 0 区分，却不足以证明达到 0.60% 的经济门槛。p = 0.005 不是“H0 为真的概率”，也不是“效应为真的概率”。

稳健性

把 α 改为 0.01：t = 3.00 仍超过 2.724，对零的结论不变；实际意义结论仍不成立。若改为单侧 μ > 0，p ≈ 0.0025，结论相同。若样本量增到 100 且均值、标准差不变，SE = 0.24，t = 5.00，95% 区间 0.72% 至 1.68%，此时 0.60% 已落在区间之外，实际意义结论会改变。若测试多个策略、多个期间或反复调整门槛，5% 的假阳性率会累积；应预先登记假设并报告全部尝试。若 36 个月存在序列相关，p 值会过小；若样本有偏，估计中心会偏移。

局限

p 值依赖抽样设计和模型假设；它不衡量效应大小、经济价值或因果。统计显著可能来自大样本和微小差异，实际显著则取决于成本、风险、容量和机会成本。置信区间也受偏差影响。事后选择门槛、只报告显著结果、把相关当因果，都会夸大证据。本文数字为假设。

复现

  1. 事前写下 H0、Ha、α 和实际意义门槛。
  2. 计算 n、x̄、s、SE、t 和自由度。
  3. 由 t 分布得到双侧或单侧 p 值。
  4. 与 α 比较，写出结论强度。
  5. 报告置信区间、效应大小和全部检验。
se = s / sqrt(n)
t = (mean - mu0) / se
p_two = 2 * (1 - pt(abs(t), df=n-1))

结论强度

在这组假设数据中，月均收益与 0 的差异在 5% 水平统计显著（t = 3.00，p ≈ 0.005，95% 区间 0.39% 至 2.01%）；但不能证明达到 0.60% 的实际门槛（单侧 p ≈ 0.071），也不证明策略有效、可复制或具有因果效应。

练习

  1. p = 0.04 是否说明效应重要？
  2. 样本增大时 p 值如何变化？实际意义是否随之改变？
  3. 解释 α 与 β 的区别，以及为什么固定样本下不能同时降低两者。
参考答案
  1. 不说明。p 值只衡量在 H0 下观察到当前或更极端结果的概率；重要性要看效应大小、区间、成本和风险。
  2. 在效应和标准差不变时，样本增大会降低标准误、提高 t、减小 p；实际意义取决于门槛和经济条件，不会自动改变。
  3. α 是 H0 为真时错误拒绝的概率，β 是 H0 为假时未拒绝的概率。固定样本下降低 α 会提高 β；要同时降低需增大样本或改进设计。
