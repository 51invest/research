领先滞后与预测

交叉相关和滞后回归能描述谁先动，但变换、窗口和多重检验都会制造“领先”；预测能力必须用样本外误差检验。

研究问题

一个假设的领先指标是否领先产出 3 个月，这种关系能否用于预测？本文用 144 个月模拟数据演示交叉相关、滞后回归和样本外检验。数据由种子 20261030 生成，不是真实数据。

数据

项目 数值
样本 144 个月
频率 月度
生成方式 c_t = 0.7c_{t-1} + N(0,1)；x_t = c_{t+3} + N(0,0.8)；y_t = c_t + N(0,0.8)。记号 N(μ,σ) 的第二参数是标准差（本表为 1 与 0.8），不是方差
相关 r(x_t, y_{t+k})，k = 0…6 0.27、0.40、0.55、0.76、0.55、0.42、0.24
滞后回归 y_{t+3} = a + b x_t b = 0.76（SE 0.055），t = 13.8，R² = 0.58，n = 141
前 105 对拟合、后 36 对检验 样本外 R² = 0.54，RMSE 1.05；基准 RMSE 1.55
前后半段 r(x_t, y_{t+3}) 0.77 与 0.76
许可 模拟数据，无外部许可

x、y 是教学模拟的月度序列，单位为任意模拟单位（无量纲）。用于交叉相关的配对数随滞后增加而减少，最长滞后 k = 6 时只剩 138 对。

方法与假设

滞后图把同一序列按固定时间位移画成散点，用于检查随机性和序列相关（NIST 1.3.3.15）。交叉相关就是 x_t 与 y_{t+k} 的相关系数，k > 0 表示 x 先动。这里对增长率做交叉相关，避免水平序列的共同趋势；共比较 7 个滞后，n = 141 时 5% 显著性阈值约为 0.165，138 对时约为 0.167。再用 y_{t+3} 对 x_t 回归。只有系数稳定、样本外优于基准，才谈得上预测；领先滞后检验的是过去值是否改善预测，不是因果。

结果

相关系数在 3 个月达到 0.76，随后回落，与设定的领先 3 个月一致。回归斜率 0.76、t = 13.8、R² = 0.58；斜率表示 x 每高 1 个单位，3 个月后的 y 平均高 0.76 个单位（模拟单位）。前 105 对估计、后 36 对检验，样本外 R² = 0.54，RMSE 1.05，低于基准 1.55（基准为训练期均值）。前后半段相关为 0.77 与 0.76，两段读数一致；但两个半段来自同一次模拟，不能当作跨样本的稳定性证据。上面全部数值由 npm run sim:leads-lags 用种子 20261030 实跑得到，npm run check:sim 会把正文与脚本输出逐项比对。把种子换成从 20261030 起的 400 个连续值重跑同一模型：3 个月相关系数均值 0.742、95% 区间 0.631–0.829；样本外 R² 均值 0.540、区间 0.194–0.769。本文报告的 0.76 与 0.54 都落在区间内，说明它们是这一设定下的常见结果，不是挑出来最好看的一次。

稳健性

  • 同时比较 7 个滞后：即使真的没有关系，7 个滞后里至少一个在 5% 水平显得显著的概率也约为 1 - 0.95^7 ≈ 30%。这是把各检验当成独立的粗略估计，相邻滞后的相关系数高度正相关时真实概率更小；无论如何，“找到显著滞后”本身不是证据。
  • 改用一阶差分或 2 至 4 个月的滞后，峰值仍在 3 个月附近，但系数与 R² 会变化。
  • 一次 36 个月样本外划分不足以证明稳定，应滚动重估并报告全部结果；预先固定滞后范围和检验次数，比事后挑选峰值更可信。

领先—滞后检验的方法学依据是 1969 年发表在《计量经济学》的论文：它用计量模型与交叉谱方法研究因果关系，是这一检验传统的起点[3]。

局限

模拟预设了领先结构，真实数据的领先期随周期、修订和制度变化。样本内 R² 不等于预测能力；领先指标也可能只是共同冲击的代理。超出观测范围的外推不可靠（OpenStax 12.5）。实时预测只能用当时发布的数据；修订后的历史会高估当时可得的信息。本文不构成对真实资产收益的预测。

复现

  1. 用固定种子生成周期成分和两个增长率序列。
  2. 对 k = 0…6 计算散点与相关系数。
  3. 估计 y_{t+3} 对 x_t 的回归。
  4. 前 105 对拟合，后 36 对计算样本外 R² 与 RMSE。
  5. 报告全部滞后、子样本和基准。

结论强度

模拟中 x 领先 y 3 个月，样本外 R² 为正，属于预测性关联。没有随机化或外生冲击，不能称为因果；真实预测还需发布时点、修订和交易成本。

工作纸：把判断拆成可复核的四栏

本文的主题是“RES-017”。读完之后，不要先记结论，先做一张四栏工作纸：第一栏写“领先滞后”的定义、分子、分母和单位；第二栏写“交叉相关”的传导渠道；第三栏写“滞后回归”的制度边界；第四栏写结论的反证信号。四栏都填满，才允许把结论带进下一步；任何一栏空白，结论就只能当作假设。

第一栏最容易偷懒。把指标写成一句“越高越好”，等于没有定义。至少要回答：它衡量的是存量还是流量，分母是产出、人口、资产还是交易量，价格是名义还是实际，时间点是期末还是期间平均。换掉其中任何一个，排序和结论都可能改变。若来源只给了一个数字而没有给出分母，先回到来源脚注，不要用相邻文章的分母替代。

第二栏要把“交叉相关”写成一条可观察的链：哪一个变量先动，经过什么中介，最后改变哪个结果。链上每一环都要有时间和单位，不能把“长期”与“季度”混写。链越长，越要标出哪一环是作者推演、哪一环有来源支持；推演可以用于教学，但不能冒充事实。

第三栏处理制度。滞后回归不是背景段落，而是样本定义：哪些主体被覆盖，哪些被豁免，规则从哪一天生效，跨境比较是否由同一套规则约束。制度不同，同样的数字会对应不同的激励；把制度差异写成行为差异，是跨市场比较里最常见的错误。若无法确认规则一致，就把比较降级为“两个独立情景”，不要给出排序。

第四栏写反证。用一句可证伪的话收尾：“如果观察到 A，在 B 时间内出现 C，则原判断成立；否则放弃。”A 必须是可观察的变量，B 必须是可以等待的时间，C 必须是可以复核的结果。三项写不清，说明结论还不可检验。最后把工作纸、来源链接和复核日期放在同一页；下一次复盘时，先看当时的四栏，而不是只看事后结果。

记录模板

把四栏压缩成一页：左栏写口径与单位，中栏写机制与制度，右栏写反证与复核日期。数据更新时只改数字，不改结论文字；若结论文字必须改，说明口径或制度变了，回到来源重做检查。记录里保留一栏反方意见，下一次复盘先问证据是否推翻了反方，再问仓位是否赚钱。

边界算例：七个滞后与一百四十次比较

文中同时比较 k = 0…6 共 7 个滞后，峰值在 k = 3 的 0.76。即使真实关系为零，7 个检验里至少一个在 5% 水平“显著”的概率约为 1 - 0.95⁷ = 30.2%；相邻滞后高度相关时真实概率会低一些，但“找到峰值”本身仍不是证据。

如果把 20 个候选指标、每个 7 个滞后一起比较，共 140 次检验；至少一次假阳性的概率约为 1 - 0.95¹⁴⁰ = 99.9%。这时必须预先固定指标和滞后范围，或用样本外检验和多重检验校正，否则几乎一定能找到一个“领先指标”。

比较次数 至少一次假阳性概率 需要的态度
7 30.2% 把峰值当作假设，不是结论
140 99.9% 预注册或用独立样本外检验

样本外也会失效。文中前 105 对拟合、后 36 对检验，样本外 R² = 0.54、RMSE 1.05，优于基准 1.55。但若领先关系在第 105 个月后消失，样本外 R² 可能转负，RMSE 会高于基准；这时样本内 0.58 的 R² 只说明过去拟合得好，不能说明未来能预测。

边界是：交叉相关的峰值不是因果，样本内拟合不是预测，比较次数越多越要怀疑“发现”。若没有预注册、没有独立样本外窗口、没有实时发布数据，领先滞后只能作为待检验的假设。若要用于真实预测，至少要做滚动重估、报告全部滞后，并把交易成本和数据修订算进去。

延伸判读

领先滞后关系最容易在样本内被“找”出来：把几十个候选变量和多个滞后期一起试，总会有一个相关性看起来显著。正确做法是先有机制假设，再限定候选变量和滞后方向，最后用样本外或独立样本验证。交叉相关要看整体形状，不只看峰值；领先变量若被修订或发布延迟，实时可用性会消失。预测能力还要与简单基线比较，否则只是把同期相关误当领先。 上述制度与定义可对照公开资料 [4]；例子中的数字均为教学假设。
