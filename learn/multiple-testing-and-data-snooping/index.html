多重检验与数据窥探

60 条无预测力的模拟规则中，按 5% 水平有 4 条“显著”；Bonferroni 门槛 0.000833 下全部不显著，而至少一条假显著的概率为 95.4%。

研究问题

如果 60 条交易规则都没有真实预测力，按 5% 水平检验，出现至少一条“显著”结果的概率有多大？Bonferroni 校正后的门槛是多少？在一组 240 个月的模拟数据中，有多少条规则会误判？数据由种子 20261037 生成，是教学模拟，不是真实策略。

方法与假设

每条规则对 240 个月的收益做单样本均值检验，原假设为平均收益为零。p 值是在原假设为真时出现至少同样极端结果的概率，它的定义与常见误读见假设检验与实际意义主文（RES-012）。α 是原假设为真时拒绝原假设的概率，即第一类错误的概率（OpenStax, 9.2）；本文取 α = 0.05 作为每条规则的拒绝门槛。进行 m 次独立检验时，至少一次误拒的概率为 1-(1-α)^m，这就是族错误率（FWER，下文复现代码里的 fwer）。Bonferroni 不等式说明：g 次比较各自按 1-α/g 的置信水平构造区间时，全部结论同时成立的置信系数至少为 1-α（NIST/SEMATECH, 7.4.6.3）；把同一不等式用于假设检验，就是给每次检验设 α/m 的门槛，使整体第一类错误率不超过 α。数据窥探指反复尝试规则、只看最好结果，却不报告尝试次数。它与前视偏差、过拟合的分工，见回测与前视偏差主文（RES-020）和样本外与过拟合主文（RES-022）。Sullivan、Timmermann 和 White（1999）用 White 的 Reality Check 自助法评估 26 条技术规则、100 年道琼斯日数据，并在完整规则族上量化数据窥探偏差[2]。本文全部模拟数字由 scripts/simulate-multiple-testing.mjs 生成：mulberry32 种子随机数、Box–Muller 正态收益、每条规则对 240 个月做单样本双侧 t 检验（df = 239，p 值用不完全贝塔函数计算），Holm 与 Benjamini–Hochberg 的判定也在该脚本内实现；重复运行同一种子得到同一组数字。

结果

60 次检验、α=0.05 时，期望假显著数为 3，至少一次假显著的概率为 1 - 0.95^60 = 95.4%。种子 20261037 的这一次模拟给出 4 条 p 值低于 0.05 的规则，最小 p 为 0.001185；Bonferroni 门槛为 0.05/60 = 0.000833，Holm 的第一步门槛同样是 0.000833，两者都拦住了全部规则（0 条通过）；Benjamini–Hochberg 在 q=5% 下给出 2 条发现。

单看最小 p 的那条规则，读者可以逐项复算：240 个月的平均收益 -0.21187（收益单位）、标准差 1.00007，均值标准误 1.00007 / √240 = 0.064554，t = -0.21187 / 0.064554 = -3.282，df = 239 的双侧 p 值为 0.001185。它"显著"，但真实效应是零——这正是 60 次比较带来的后果。

把同一实验重复 200 次（从种子 20261037 起连续取 200 个种子），每次 p<0.05 的规则数均值为 3.03、标准差 1.91、范围 0 至 10，94% 的重复里至少出现一条假显著，与 95.4% 的理论值一致。

稳健性

  • 若 60 次检验相关，95.4% 只是独立假设下的近似；Bonferroni 仍控制族错误率，但更保守。
  • 把候选规则增到 200 条，门槛降为 0.05/200 = 0.00025，期望假显著数升到 200 × 0.05 = 10；该口径可用 node scripts/simulate-multiple-testing.mjs 20261037 200 240 直接跑出。
  • 校准检查：node scripts/simulate-multiple-testing.mjs --check 用 5,000 条零效应规则复跑，p<0.05 的比例为 5.16%、p 值均值 0.5011、p 值小于 0.25/0.5/0.75 的比例为 0.252/0.497/0.748，与原假设下 p 值应近似均匀的预期一致；--selftest 则把 p 值函数对已知 t 分位数对照（如 t=1.96、df=239 得 0.0512）。
  • Holm 与 Bonferroni 控制同一个族错误率，但通常更有功效；Benjamini–Hochberg 改控制错误发现率，目标不同。本文的 Holm 与 BH 判定由复现脚本自行实现，属方法学表述，登记的三条来源不覆盖它们；两者都不豁免报告全部尝试和选择过程的要求。
  • 换一段样本，p 值会变；单次显著不等于可复现。

局限

模拟规则独立且近似正态，真实策略存在相关性和非正态性；检验只覆盖一种规则族。未计交易成本、数据修订和发表偏差，也未报告效应量和置信区间。Bonferroni 控制的是错误率，不是每个结论为真的概率；校正后仍可能有假阳性。结论不支持任何真实规则的有效性。

复现

  1. node scripts/simulate-multiple-testing.mjs 用种子 20261037 生成 60 条规则、240 个月的零均值收益，逐条计算 t 统计量与 df=239 的双侧 p 值。
  2. 读脚本输出：p<0.05 的规则数、最小 p、期望假显著数与 Bonferroni/Holm/BH 判定。
  3. --selftest 校验 p 值函数，--check 校验 p 值均匀性，--repeat 200 给出假显著数的抽样分布。
  4. 换规则数或月份数（位置参数 seed rules months）检查结论是否翻转。
  5. 报告尝试次数、相关结构和全部 p 值，而不只报告最小 p。
node scripts/simulate-multiple-testing.mjs          # seed rules months = 20261037 60 240
expected_false = 60 * 0.05 = 3
fwer = 1 - 0.95^60 = 0.9539
bonferroni = 0.05 / 60 = 0.000833
min_p = 0.001185 (mean -0.21187, sd 1.00007, se 0.064554, t -3.282)
naive_sig = 4; bonferroni_sig = 0; holm_sig = 0; bh_discoveries(q=0.05) = 2
--repeat 200 -> mean_hits 3.03, sd 1.91, range 0..10, share_with_hit 0.94
--check      -> 5000 rules: share p<0.05 = 0.0516, mean p = 0.5011

结论强度

4 条“显著”结果与零预测力一致，是多次比较的产物；Bonferroni 门槛把它们全部排除。结论支持预先登记假设、报告尝试次数并使用多重检验校正，不支持把单次显著结果当作策略有效的证据。

还要区分两种错误控制：FWER（族错误率）控制“至少一次误拒”的概率，Bonferroni 和 Holm 属于这一类，较保守；FDR（错误发现率）控制“被判定显著的结果中假结果的比例”，Benjamini–Hochberg 属于这一类，在大量检验时更有功效。本文的 BH 在 q=5% 下给出 2 条发现，不代表这 2 条就是真的；FDR 允许一定比例的假发现，适合探索性研究，不适合单策略决策。

分叉路径（garden of forking paths）比显式尝试 60 条规则更隐蔽：研究者没有记录所有尝试，只报告最终那条“显著”的规则。解决方式不是事后编一个门槛，而是事前写明假设、样本、规则族和停止规则；如果做不到，就把结果标为探索性，并用独立样本复现。多重检验校正只能处理“已知的尝试次数”，处理不了“未报告的尝试”[1][2]。

练习

  1. 60 次独立检验、α=0.05，期望假显著数是多少？
  2. 至少一次假显著的概率是多少？
  3. 最小 p=0.001185，Bonferroni 门槛 0.000833，是否显著？
  4. 为什么数据窥探会抬高回测结果？
  5. FWER 与 FDR 各控制什么？哪一种更适合探索性研究？
  6. 什么是“分叉路径”？为什么它比显式尝试 60 条规则更难处理？
参考答案
  1. 60 × 0.05 = 3。
  2. 1 - 0.95^60 = 95.4%。
  3. 不显著；0.001185 > 0.000833，Holm 第一步用的也是 0.000833，同样拦住。
  4. 因为只报告最好的尝试，选择次数被隐藏；最大值容易被偶然高值占据。
  5. FWER 控制“至少一次误拒”的概率，Bonferroni、Holm 属于此类，较保守；FDR 控制“被判显著的结果中假结果的比例”，BH 属于此类，在大量检验时更有功效，更适合探索性研究。
  6. 分叉路径指研究者没有记录所有尝试，只报告最终“显著”的那条规则；校正只能处理已知尝试次数，处理不了未报告的尝试。
