多源测量的三角验证：卫星、文本与行政数据

单一数据源都有盲区：卫星看不到地下经济，文本有选择性偏差，行政数据有申报激励。三角验证不是“多找几个来源”，而是用独立误差结构互相校验，估计真实值的区间。

研究问题与定义

三角验证是用多个独立来源测量同一现象，通过误差结构互补来缩小不确定性。它不等于“多找几个来源”，而是要求来源之间的误差不相关。

三类来源的盲区：卫星（夜间灯光、作物遥感）覆盖广、频率高，但看不到地下经济、服务活动和收入分配；文本（新闻、合同、社交媒体）信息丰富，但有选择性和平台偏差；行政数据（税务、社保、登记）覆盖特定人群，但受申报激励和口径变化影响。

三角验证的核心是：如果三个来源都指向同一区间，结论更可信；如果分歧大，要解释分歧，而不是简单平均[1][2]。

数据与算例

假设要估计某地区经济活动增长率。卫星灯光估计 4%，文本情绪估计 6%，税务登记估计 3%。三者差异大，不能直接平均为 4.3%。

先查误差：灯光可能受电力普及和价格影响；文本可能受媒体报道偏向；税务登记可能漏掉非正规部门。若灯光与税务覆盖同一正规部门，二者误差相关，不能算独立验证。

若三者独立且分别给出 3%—6% 区间，可以用区间交集和加权中位数报告 4%—5%，并说明不确定性。三角验证的目标不是精确点估计，而是可信区间。以上数字均为教学假设。

输入与假设

三角验证需要三类输入：卫星影像（夜间灯光、NDVI、建筑轮廓）、文本语料（新闻、合同、社交平台）和行政记录（税务、社保、工商登记）。每条输入都要带地理编码、时间戳、单位、覆盖范围和采集口径；先把行政区划、企业标识和个人标识对齐，再谈“互相验证”。关键假设有三个：三类来源测量的是同一个经济构造；误差结构彼此独立；报告口径在可比时期内稳定。任何一个假设不成立，三角验证就退化为“多找几个数字”。

方法与步骤

检查一：独立性。 来源是否共享同一底层数据、同一采集过程或同一利益相关方？共享越多，验证价值越低。

检查二：覆盖一致性。 三个来源是否测量同一 population、同一时期、同一定义？口径不同要先对齐。

检查三：误差方向。 每个来源的误差是向上还是向下？若都向上，平均会放大偏差；要分别校正。

三角验证还要记录数据版本、清洗规则和不确定性；可复现性比“多源”更重要[3][4]。

失败条件与边界

边界一：多源不等于独立。 如果三个来源都引用同一份统计，它们不是独立验证；要看采集过程。

边界二：卫星不是万能。 灯光和遥感能测活动和土地变化，但测不了收入分配、服务质量和制度；要与其他来源结合。

边界三：文本有叙事偏差。 新闻和社交媒体受平台、语言和事件影响；不能把热度当成事实。

误解一：三个来源平均就是三角验证。 平均会掩盖分歧；要先检查独立性和误差方向。

误解二：行政数据最准确。 行政数据覆盖特定人群，漏报和申报激励会导致系统性偏差；它不是真值。

结果解读：三角验证、卫星数据与行政数据

三角验证不是“多找几个数据源”，而是用相互独立的测量验证同一构念。卫星影像、文本、行政记录和调查各有误差，且误差来源不同；若三者指向同一结论，可信度更高，若分歧，要解释为什么。

卫星数据的优势是覆盖广、频率高、可回溯；劣势是分辨率、云层、算法和地面真值。夜间灯光、作物 NDVI、建筑足迹、船舶 AIS 都需要校准；灯光与经济活动的关系非线性，不能直接当 GDP。

文本数据（新闻、财报、社交媒体）能捕捉预期和情绪，但受平台选择、语言、审查和算法影响；词频不等于经济变量，需要人工标注、主题模型和外部验证。

行政数据（税务、社保、海关、登记）覆盖全、定义清楚，但可能滞后、口径变化、访问受限；行政记录与调查的定义差异会导致不可比。

匹配与隐私：微观匹配需要个体标识，受隐私法限制；差分隐私、聚合和合成数据可以降低风险，但会损失精度。

三角验证的设计：先明确构念和误差结构，再选独立数据源；若数据源相关（同一调查衍生），不能算独立验证。

测量：覆盖率、频率、误差、口径一致性、匹配率。单一数据源的精度不等于整体可信度。

常见误用：把卫星灯光当 GDP、把词频当情绪、把行政数据当无误差、把相关数据源当独立验证。

最后，三角验证的价值是“误差不相关”；若误差同源，再多数据也只是重复同一个偏差。

复现与检查清单

复现清单至少包含：数据版本与下载日期、影像云量和预处理参数、文本抓取关键词与去重规则、行政数据的申报口径和修订版本、地理和时间对齐方法、缺失值处理、区间合成规则，以及不确定性来源。代码要能从原始文件重跑出同一张区间表；若某一步依赖人工判断，写明判断规则和复核人。复现不是追求完全相同的点估计，而是让读者能检查每个来源怎样进入最终区间。

多源判读清单

拿到一组“多源验证”的结论，先问五项：

  1. 来源真的独立吗？ 共享底层数据、同一采集机构或同一利益相关方，会让“多源”变成同一误差的多次复制。
  2. 测量的是同一个构念吗？ 灯光、文本情绪和税务登记可能分别代理活动、信心和正规部门；口径不对齐，交集没有意义。
  3. 误差方向是否已知？ 每个来源偏高还是偏低、在什么条件下偏；都偏高时平均会放大偏差。
  4. 区间如何合成？ 交集、加权中位数和贝叶斯更新各有假设；要报告不确定性来源和权重。
  5. 能否复现？ 数据版本、清洗规则、地理对齐和代码是否公开；不能复现的多源只是多个故事。

三角验证的价值在于“独立误差互相校验”，不是“来源数量多”。

反证条件

三角验证的结论依赖独立性和口径：

  1. 来源共享底层数据。 若卫星、文本和行政数据都来自同一采集系统或同一机构，误差高度相关，验证价值下降。
  2. 构念不对齐。 若灯光代理活动、文本代理情绪、税务代理正规部门，三者测的不是同一件事，交集无意义。
  3. 误差方向未知。 若三个来源都系统性偏高，平均会放大偏差，而不是缩小。
  4. 区间合成假设错误。 若把独立来源的区间直接平均，忽略权重和相关性，不确定性被低估。
  5. 无法复现。 若数据版本、清洗规则和代码不公开，多源结论只是多个故事。

实践含义： 多源验证要先证独立、再证同构、最后合成区间；来源数量不等于信息量，独立误差才值钱。

数据附注： 报告每个来源的缺失率、覆盖率和误差方向；缺失不是随机时，区间合成会偏。

范围说明： 按群体报告缺失率和覆盖率；总体缺失率会掩盖小地区和高收入群体的偏差。

最后： 按群体报告缺失率；总体缺失率会掩盖小地区和高收入群体的偏差。

  2. 三个来源估计 4%、6%、3%，可以直接平均吗？

  3. 若灯光与税务同源，为什么不能算独立验证？

  4. 如何用区间交集报告结果？

延伸阅读：卫星、文本与行政数据研究

卫星经济学：Henderson 等用夜间灯光验证 GDP 和城市化；Chen 与 Nordhaus 用灯光校准区域产出；作物 NDVI、船舶 AIS 和建筑足迹被用于贸易、活动和基础设施研究。

文本即数据：Gentzkow、Kelly 和 Taddy 综述了文本在经济学中的应用；词频、主题模型和嵌入要配合人工验证，不能直接把“情绪”当变量。

行政数据：Chetty 等用税务记录研究流动性、社区和代际流动；行政数据的优势是全样本，劣势是定义、访问和隐私。

三角验证：混合方法研究强调“误差独立”和“构念一致”；多源数据要报告区间、分歧和解释，而不是简单平均。

阅读建议：先读一篇卫星、一篇文本、一篇行政数据的经典应用，再设计自己的三角验证；重点是误差结构，不是数据数量。

本章要点

  • 三角验证要求误差独立，不是数据源越多越好。
  • 卫星数据覆盖广但受分辨率、云层、算法和地面真值限制。
  • 文本数据受平台、语言、审查和算法影响，词频不等于变量。
  • 行政数据覆盖全但可能滞后、口径变化、访问受限。
  • 报告区间、分歧和解释，比简单平均更可信。
