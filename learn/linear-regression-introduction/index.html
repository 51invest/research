线性回归入门

线性回归用一条直线概括两个变量的平均关系；斜率、截距和 R² 描述样本，显著性和因果解释取决于设计、假设与证据边界。

模块RES-M06 · 回归与计量
层级入门
阅读7 分钟 · 13 节

研究问题

一个假设的 48 个月样本：某基金月度超额收益 y 与市场月度超额收益 x。问题：x 每高 1 个百分点，y 平均高多少？这条线能否用于预测和解释？本文只做描述与统计推断，不把相关写成因果。所有数值为教学假设，不是真实市场数据。

数据

项目 数值
样本量 n 48
x 均值 0.50% / 月
y 均值 0.80% / 月
x 样本标准差 2.00 百分点
y 样本标准差 2.80 百分点
相关系数 r 0.8571
观测范围 x 约 -3.6% 至 4.2%

数据为假设的月度观测；未做季调；均值以 % / 月 表示，标准差与系数变化以百分点表示。

方法与假设

最小二乘回归线写作：

y = a + b x

斜率 b = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²，截距 a = ȳ - b x̄（OpenStax 12.3）。b 表示 x 每增加一单位时 y 的平均变化。R² = r² 是样本内被线性拟合解释的方差比例（OpenStax 12.3）。推断假设：线性关系、误差独立、同方差、残差近似正态，且数据来自设计良好的随机抽样或随机化实验；相关系数检验的原假设为 ρ = 0（OpenStax 12.4）。本例是假设的月度时间序列，不是随机抽样，检验结果只能作为近似参考。

结果

b = 1.20，a = 0.20%，R² = 0.735。回归标准误 s_e = 1.46 百分点；斜率标准误 0.106，t = 11.29（df = 46），p < 0.001，95% 区间 0.99 至 1.41。

解释：样本中市场超额收益每高 1 个百分点，基金超额收益平均高 1.20 个百分点；市场收益为 1.00% 时，预测基金收益为 0.20% + 1.20 × 1.00% = 1.40% / 月。R² = 0.735 表示样本内约 73.5% 的 y 方差可由这条线解释，不表示因果解释力为 73.5%，也不保证样本外预测。

稳健性

  • 使用稳健标准误，斜率标准误约 0.11，结论不变。
  • 剔除残差绝对值最大的 2 个观测，b ≈ 1.16，R² ≈ 0.71，方向不变。
  • 样本分为前后两半，b 分别约为 1.05 和 1.34，均显著，区间有重叠。
  • 若 x 超出观测范围（例如 6.00%），预测属于外推，线性关系未必保持（OpenStax 12.5）。
  • 若误差存在序列相关或异方差，常规标准误和 t 值会失真，应使用稳健方法或时间序列模型。

局限

回归只描述样本中的平均线性关系。遗漏变量、测量误差、反向因果和选择偏差都会使 b 偏离目标；R² 高也不代表模型正确。48 个月不足以稳定估计长期关系，市场结构变化会改变参数。相关不等于因果（OpenStax 12.3）。本文数值为假设，不能用于投资决策；读者应把它当作方法练习，而不是对某只基金的评价。

复现

  1. 固定样本、频率和变量定义，画出散点图。
  2. 计算 x̄、ȳ、s_x、s_y、r。
  3. 用上述公式求 b、a、残差和 R²。
  4. 计算 s_e、SE(b)、t 和 95% 区间。
  5. 检查残差图、异常值和样本外预测。
b = sum((x - mean(x)) * (y - mean(y))) / sum((x - mean(x))^2)
a = mean(y) - b * mean(x)
r2 = corr(x, y)^2
se_b = sqrt(sum(resid^2) / (n - 2) / sum((x - mean(x))^2))

结论强度

在这组假设数据中，市场超额收益与基金超额收益呈较强的样本内线性关系（b = 1.20，95% 区间 0.99 至 1.41，R² = 0.735）。这是关联与预测描述，不是因果效应；外推到观测范围之外、其他时期或其他基金需要额外证据。

说明：标准误、置信区间与稳健性数字用于说明方法和方向。其中稳健性一节的四项数字是教学示意，不能仅凭文中汇总量复算，不应作为精确估计引用。

知识点精读

控制变量

定义：控制变量是在回归中加入其他解释变量，以隔离目标变量的偏效应。

机制：控制变量可减少遗漏偏差，但坏控制会引入过度控制、共线性和中介效应；选择应基于因果图和机制。

例子：例如研究教育对收入的影响时控制年龄、地区和家庭背景，但不能控制毕业后职业这一中介。

边界：控制不是越多越好；控制中介会挡住真实效应，控制碰撞变量会制造偏差，测量误差和共线性也会使系数不稳定。

估计诊断

定义：估计诊断是检查回归结果是否可信，包括残差、拟合、共线性、影响点和模型设定。

机制：残差图查非线性和异方差，VIF 查共线性，Cook 距离查异常影响，R² 和标准误查拟合与精度。

例子：例如残差呈漏斗形提示异方差，某点 Cook 距离很大提示强影响。

边界：诊断不是形式；通过诊断不等于因果正确，R² 高也可能过拟合，诊断图主观且遗漏变量偏差不会被残差发现，需结合设计。

异方差

定义：异方差是误差方差随观察或解释变量变化，不满足同方差假设。

机制：异方差使普通标准误有偏，但系数仍可能一致；可用稳健标准误、加权最小二乘或变换处理。

例子：例如收入越高消费波动越大，误差方差随收入上升。

边界：异方差不是致命错误；它主要影响推断效率，稳健标准误可修正但样本小不稳定，遗漏变量和非线性也可能伪装成异方差。

自相关

定义：自相关是误差在时间上相关，即相邻或滞后观测的误差不独立。

机制：自相关使标准误低估、t 值偏大；可用 Newey-West、模型动态或差分处理，但需区分真实动态和遗漏变量。

例子：例如月度数据中误差持续正相关，普通回归显著性被高估。

边界：自相关不是只存在于时间序列；空间和分组数据也有相关，稳健标准误不能修复错误模型，滞后选择和单位根也需处理。

内生性

定义：内生性是解释变量与误差相关，导致回归系数有偏，来源包括遗漏变量、反向因果、测量误差和 simultaneity。

机制：内生性不能靠控制所有变量解决，需工具变量、实验、面板固定效应或结构模型；方向和机制决定方法。

例子：例如教育影响收入，但能力同时影响教育和收入，遗漏能力使教育系数偏高。

边界：内生性不是技术细节；它决定能否因果解释，工具变量需相关且外生，固定效应不能解决时变遗漏，测量误差会衰减系数。

离散与面板模型

定义：离散模型处理二值、计数或类别结果，面板模型处理同一单位跨时间的重复观察。

机制：logit/probit 用于二值，泊松用于计数，面板用固定或随机效应控制不随时间变化的个体差异。

例子：例如研究是否违约用 logit，研究多期企业投资用面板固定效应。

边界：模型不是按结果类型随便选；离散模型系数解释非线性，固定效应不能估计不随时间变化的变量，随机效应假设个体效应与解释变量不相关，聚类标准误也重要。

练习

  1. 斜率 1.20 的单位是什么？
  2. R² = 0.735 是否说明模型解释了 73.5% 的因果效应？
  3. 为什么在 x = 6.00% 处预测要谨慎？
参考答案
  1. y 的百分点除以 x 的百分点；x 每增加 1 个百分点，y 平均增加 1.20 个百分点。
  2. 不是。R² 是样本内方差比例，不衡量因果，也不保证样本外预测。
  3. 6.00% 超出观测范围（约 -3.6% 至 4.2%），属于外推，线性关系可能不成立。
