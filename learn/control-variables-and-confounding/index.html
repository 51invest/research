控制变量与混杂

控制变量用于阻断混杂路径，而不是把所有可得变量都放进回归；简单相关在调整混杂后会减弱，但调整本身也可能引入新偏差。

模块RES-M07 · 因果推断

研究问题

一个假设的 72 个月样本：基金月度超额收益 y、标准化投资者情绪指数 x、市场月度超额收益 z。简单回归显示 x 与 y 正相关。问题：加入 z 后，x 的系数还剩多少？z 是混杂变量、中介变量还是其他结构？本文说明控制变量的选择逻辑和证据边界。所有数值为教学假设，不是真实市场数据。

数据

项目 数值
样本量 n 72
y 均值 / 标准差 0.70% / 0.77 百分点
x 均值 / 标准差 0 / 1.00
z 均值 / 标准差 0.55% / 4.00 百分点
x 与 z 的相关 0.60
简单回归 x 斜率 0.45（SE 0.075）
多元回归 x 斜率 0.10（SE 0.062）
多元回归 z 斜率 0.146（SE 0.0156）
R² 0.34 → 0.71

x 为标准化情绪指数（无量纲），z 为市场超额收益；数据为假设的月度观测，非真实数据。这组数字来自一个可复算的设定：真实模型为 y = 0.10·x + 0.146·z + u，其中 u 的标准差 0.41 百分点，corr(x,z)=0.60；由此得 y 的标准差 0.77 百分点，R²=0.71。把 y 单独对 x 回归会得到斜率 0.10 + 0.146 × 2.40 = 0.45，这正是"遗漏混杂"后的偏误量。标准误用总体近似式给出：简单回归 SE(b)=s_e/(s_x·√(n-2))，多元回归 SE=s_e/(s_x·√(n-3)·√(1-corr(x,z)²))；表内数值已四舍五入，用抽样数据复算会有约 0.01 的出入。

方法与假设

简单回归为 y = a + b x；多元回归为 y = a + b x + c z。混杂指多个因素对结果的影响无法分开；两个变量之间有关联，并不意味着一个导致另一个（OpenStax 1.2）。若 z 同时影响 x 和 y，且不是 x 的结果，则 z 是混杂变量，遗漏它会使 b 有偏。遗漏变量偏差近似为 c × δ，其中 c 是多元回归里 z 的系数，δ 是把混杂对被解释变量回归、即 z = d + δ·x + e 得到的斜率（在标准差口径下 δ = corr(x,z)·s_z/s_x）。控制变量应阻断后门路径，而不是任意加入：控制中介变量会拿走部分目标效应，控制对撞变量会引入新偏差。线性、独立、同方差和正确函数形式仍是前提。设计实验时，区组也可以把干扰因素控制住（NIST 5.3.3.2）。

结果

简单回归：b = 0.45（SE 0.075，t = 6.00，95% 区间 0.30 至 0.60），R² = 0.34。

多元回归：b = 0.10（SE 0.062，t = 1.61，p ≈ 0.11，95% 区间 -0.02 至 0.22），c = 0.146（SE 0.0156，t = 9.36），R² = 0.71。两个回归的被解释变量都是基金月度超额收益（百分点）；b 按 x 每 1 个标准差计价，c 按 z 每 1 个百分点计价。

corr(x,z)=0.60 给出 δ = 0.60 × 4.00 / 1.00 = 2.40，于是遗漏变量偏差 c × δ = 0.146 × 2.40 = 0.35，恰为 0.45 - 0.10 的差异。加入 z 后，x 的关联从 0.45 降到 0.10 且不再显著。一个合理读法是：简单回归中的大部分关联来自市场暴露，而不是情绪独立的效应。但“合理”不等于“已证明”。

图 1 的两条线说明控制前后斜率变了；图 2 把“为什么”画成一条后门路径：z 同时影响 x 和 y，不控制它，x 与 y 的关联会混入市场暴露；控制 z 后，斜率从 0.45 降到 0.10。

稳健性

下列各项的数值同样是教学假设，用于说明该做哪些检查，不能由上文的设定推出。

  • 加入 z 的两期滞后，x 系数 0.08（SE 0.10），仍不显著。
  • 使用 HAC 稳健标准误，x 的 SE 约 0.10，结论不变。
  • 前后两半样本的 x 系数为 0.12 和 0.07，均不显著，区间变宽。
  • 改用另一种情绪指标，x 系数 0.11（SE 0.09）。
  • 若 z 是 x 的中介，控制 z 会低估总效应；若 z 是 x 的结果或对撞变量，控制反而引入偏差。仅凭数据无法完全区分这些结构，需要制度知识和时间顺序。

局限

观察性设计不能证明因果：不能随机分配时，组间除了解释变量还会有其他差异；随机分配把潜在差异大致均衡地分到各组，实验才能把处理效应与这些因素分开（OpenStax 1.4）。中介、对撞与后门路径按因果推断的通行术语使用，属于本文自己的方法学表述；本文登记的三条来源只覆盖混杂定义、随机分配与区组设计，不覆盖这两类错误控制。z 可能有测量误差，也可能遗漏规模、风格、费用等其他混杂；函数形式可能错误；72 个月只覆盖有限市场环境。控制变量不是越多越好，错误控制会制造偏差。本文数值为假设，不能据此评价真实基金或策略。

复现

  1. 明确 y、x、z 的时间顺序、定义和单位。
  2. 先跑简单回归，记录系数、SE 和 R²。
  3. 画 x 与 z、y 与 z 的散点图，判断 z 是否同时影响两者。
  4. 加入 z，比较系数变化；报告辅助回归 δ 和偏差方向。
  5. 做稳健标准误、子样本和替代口径检查。
  6. 明确写出不能排除的混杂。
short: y ~ x
long:  y ~ x + z
aux:   z ~ x          # δ = 辅助回归中 x 的斜率
bias ≈ coef(x in long) * δ
       = 遗漏变量偏差（相对 short 中 x 的斜率）

结论强度

样本中 x 与 y 的简单关联为 0.45；控制市场收益 z 后降到 0.10 且不显著。这支持“简单关联大部分由市场暴露混杂”的解释，但不证明 x 没有因果作用，也不证明 z 是唯一混杂。结论是条件关联，不是因果效应。

知识点精读

因果图

定义：因果图是用节点和箭头表示变量间因果关系的图，常见有向无环图（DAG）。

机制：DAG 帮助识别混杂、碰撞和中介，指导控制变量选择；后门准则和前端准则可判断可识别性。

例子：例如教育→收入，能力→教育和收入，能力是混杂，需控制；若控制毕业后职业这一中介，会挡住部分效应。

边界：因果图不是事实；箭头方向依赖领域知识和假设，未观测变量和反馈回路会限制识别，图错了控制策略也会错。

混杂

定义：混杂是第三变量同时影响处理和治疗结果，使观察到的关联混入非因果成分。

机制：混杂造成虚假或夸大的效应；随机化、匹配、回归控制和工具变量可缓解，但需知道混杂因素。

例子：例如冰淇淋销量与溺水相关，天气同时影响两者，天气是混杂。

边界：混杂不是相关本身；未观测混杂难以控制，控制碰撞或中介会引入新偏差，匹配也可能遗漏重要变量，因果解释需设计支持。

随机实验

定义：随机实验把处理随机分配给对象，使处理组和对照组在期望上可比，是因果识别的黄金标准。

机制：随机化消除可观测和不可观测混杂，平均处理效应可识别；样本量、依从性和外部有效性影响结论。

例子：例如随机一半患者用新药、一半用安慰剂，比较结果差异。

边界：随机不是万能；不依从、 attrition、伦理和成本限制实验，随机化只保证内部有效，特定样本的结论未必适用其他人群。

自然实验

定义：自然实验是利用政策变化、地理边界或偶然事件造成的近似随机差异识别因果。

机制：自然实验依赖外生冲击和可比性；政策断点、天气、灾害和制度变化常被使用，但需检验冲击是否真的外生。

例子：例如某地提高最低工资、邻地不变，可比较就业变化。

边界：自然实验不是真实验；外生性常受质疑，处理和政策同时变化，迁移和预期会污染对照，结论依赖具体制度和时期。

工具变量

定义：工具变量是与处理相关、但与结果误差不直接相关的变量，用于分离处理的因果效应。

机制：工具变量需满足相关性（与处理相关）和外生性（只通过处理影响结果）；两阶段最小二乘常用。

例子：例如用距离或政策变化作为教育年限的工具，估计教育对收入的效应。

边界：工具变量不是随便找相关变量；弱工具、排除限制失败和局部效应会误导，外生性无法完全检验，估计的是特定人群的局部效应。

双重差分和断点

定义：双重差分比较处理组和对照组在处理前后的变化，断点回归利用阈值两侧的近似随机差异。

机制：DID 依赖平行趋势假设，断点依赖阈值附近连续性和无操纵；两者都需检验安慰剂和稳健性。

例子：例如某市实施政策，比较该市与相似城市前后变化；高考分数线附近比较录取结果。

边界：方法不是自动因果；平行趋势可能不成立，断点两侧可能有操纵和混淆，样本窗口和函数形式影响结果，政策外溢也会污染对照。

练习

  1. 控制变量与混杂变量有什么区别？
  2. 为什么控制中介变量会改变目标效应？
  3. 如果 z 是对撞变量，控制它会怎样？
参考答案
  1. 混杂变量同时影响处理与结果，是需要在设计中或回归中阻断的第三条路径；控制变量是为此目的加入模型的变量，不是任何可得变量。
  2. 中介位于处理到结果的因果链条上；控制它会拿走一部分本应计入总效应的变化，估计的是直接效应而非总效应。
  3. 控制对撞变量会打开原本关闭的路径，可能引入选择偏差，使系数偏离目标。
