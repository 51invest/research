概率分布与期望方差

概率分布用每个可能结果的概率描述随机变量；期望是长期平均，方差与标准差衡量离散程度。它们描述假设的分布，不预测下一期结果。

研究问题

一个假设的月度收益分布只有三种结果：-2%、0% 和 +4%，概率分别为 0.25、0.45 和 0.30。平均结果是多少，波动有多大？期望 0.70% 是否意味着下个月会赚 0.70%？本文区分概率分布、期望与方差，说明它们能回答什么，不能回答什么。所有数值都是教学假设，不是真实基金数据。

数据

结果 x（%） 概率 P(x) 说明
-2 0.25 亏损
0 0.45 持平
+4 0.30 上涨
合计 1.00 概率之和必须为 1

结果互斥且穷尽；概率之和为 1.00。概率是假设值，不是从历史数据估计的频率。

方法与假设

离散随机变量 X 的分布列出每个取值及概率；每个概率在 0 与 1 之间，所有概率之和为 1（OpenStax 4.1）。期望值是概率加权平均：

μ = Σ x · P(x)

方差是离差平方的概率加权平均：

σ² = Σ (x - μ)² · P(x)

标准差是方差的正平方根，单位回到百分点（OpenStax 4.2；NIST 把方差定义为到均值平方距离的平均，标准差开方后恢复原单位）。

关键假设：结果互斥且穷尽；概率已知并在期间内稳定；观察独立同分布；只讨论单期。期望是重复多次后的长期平均，不是最可能结果，也不保证在任何一期实现。

结果

μ = 0.25×(-2) + 0.45×0 + 0.30×4 = 0.70（%）。

σ² = 0.25×(-2.70)² + 0.45×(-0.70)² + 0.30×(3.30)² = 1.8225 + 0.2205 + 3.2670 = 5.31（%²）。

σ = √5.31 ≈ 2.30（百分点）。

期望 0.70% 不是可能结果；0% 的概率最高（45%），亏损概率为 25%。方差单位是百分点的平方，不能与收益率直接比较，所以同时报告标准差 2.30 个百分点。只报期望会隐藏 25% 的亏损概率和 2.30 个百分点的波动。

稳健性

把概率改为 0.20、0.50、0.30，期望变为 0.80%，方差变为 4.96（%²）；方向不变，但数值对概率假设敏感。若加入一个 -10% 的尾部结果并相应缩小其他概率，方差会明显上升，说明方差对极端值敏感；NIST 也指出重尾会扭曲标准差。若用 36 个独立观察估计期望，标准误约为 2.30/√36 ≈ 0.38 个百分点，这是抽样不确定性，不是分布本身的波动；抽样设计与区间估计另见抽样与置信区间主文（RES-011）。若月度结果相关，12 个月的方差不能简单按 12 倍相加；两个序列的联合变动见协方差与相关性主文（RES-010）。

局限

概率未知，且会随制度、市场状态和投资者行为变化；历史频率不等于未来概率。收益分布常有偏、厚尾，方差对上下波动同等惩罚，也不区分亏损顺序。期望和方差没有描述尾部损失、路径依赖、流动性和交易成本。样本估计还会受幸存者偏差和多重尝试影响。本文数字是假设，不是对任何基金的评价。

复现

  1. 列出互斥且穷尽的结果与概率，检查概率之和为 1。
  2. 计算期望 μ。
  3. 用每个离差平方乘以概率，求和得到方差。
  4. 对方差开平方得到标准差，并注明单位（写法见数据单位与统计口径主文，RES-001）。
  5. 报告概率来源、样本量、期间和独立性假设。
x = [-2, 0, 4]
p = [0.25, 0.45, 0.30]
mu = sum(xi * pi for xi, pi in zip(x, p))
var = sum(pi * (xi - mu) ** 2 for xi, pi in zip(x, p))
sd = var ** 0.5

结论强度

在给定假设分布下，期望为 0.70%，标准差为 2.30 个百分点；这是对分布的描述性计算，不是对真实收益的估计或预测，也不构成因果结论。若概率来自样本，还需要抽样设计和置信区间；若概率来自主观判断，结论只在该判断成立时有效。

知识点精读

随机变量

定义：随机变量是把随机试验结果映射为数值的函数，分为离散和连续。

机制：离散变量取有限或可数取值，连续变量取区间值并有概率密度；分布、期望和方差描述其行为。

例子：例如掷骰子点数是离散随机变量，股票日收益率可建模为连续随机变量。

边界：随机变量不是随意数字；概率模型和样本空间决定含义，连续变量单点概率为零，实际数据离散化和截断会改变分布。

分布

定义：分布描述随机变量取各值的概率或密度，常见正态、二项、泊松、均匀和厚尾分布。

机制：分布由均值、方差、偏度和尾部形状刻画；正态适合近似对称数据，二项计数成功次数，厚尾适合极端事件。

例子：例如多次独立抛硬币可用二项分布，金融收益常有厚尾和偏度，正态会低估极端损失。

边界：分布不是标签；错误假设会低估风险，混合、截断和时变分布使单分布失效，拟合优度也不能证明真实生成过程。

期望

定义：期望是随机变量的概率加权平均值，表示长期重复试验的平均结果。

机制：离散期望是取值乘概率求和，连续期望是积分；期望线性，但乘积的期望只在独立时等于期望乘积。

例子：例如公平骰子的期望点数是 3.5，组合期望收益是权重乘各资产期望收益。

边界：期望不是最可能结果；厚尾分布中期望可能被极端值主导或不存在，样本均值收敛慢，期望也不等于可实现收益。

方差

定义：方差是随机变量偏离期望的平方的平均，标准差是方差的平方根，衡量离散程度。

机制：方差越大波动越大，标准差与数据同单位便于解释；协方差和相关性把方差扩展到多变量。

例子：例如两只基金平均收益相同，方差更小者波动更低。

边界：方差不是完整风险；它把上下波动同等对待、忽略尾部和偏度，厚尾和极端损失可能被低估，方差也可能因样本和频率变化。

协方差

定义：协方差衡量两个随机变量一起偏离各自期望的方向和程度，相关性是标准化后的协方差。

机制：正协方差表示同向变动，负值表示反向；相关系数在 −1 到 1 之间，便于跨变量比较。

例子：例如股票和债券常负相关，分散组合可降低波动；同行业股票协方差高。

边界：协方差不是因果；相关可能由共同因子、伪相关或非线性造成，危机时相关性上升，协方差估计也受样本和异常值影响。

抽样

定义：抽样是从总体中选取一部分观察，常见简单随机、分层、整群和系统抽样。

机制：抽样方法决定样本代表性和误差；概率抽样可计算标准误，非概率抽样易有选择偏差。

例子：例如分层抽样按行业比例抽取企业，简单随机抽样给每个单位相等机会。

边界：抽样不是随便取数；覆盖不足、幸存者和自选择会使样本偏离总体，样本量大也不消除偏差，方便样本不能推断总体。

估计和不确定性

定义：估计是用样本推断总体参数，点估计给出一个值，区间估计和标准误给出不确定性。

机制：常见估计有均值、比例、回归系数和方差；无偏性、一致性和效率评价估计量，标准误反映抽样波动。

例子：例如用样本平均估计总体平均，标准误随样本量增大而减小。

边界：估计不是真值；偏差、模型错误和抽样波动会造成偏离，标准误只覆盖抽样不确定性，不覆盖偏差和设定错误。

练习

  1. 把三个概率改为 0.20、0.50、0.40，有什么问题？
  2. 若 x = 0 的概率为 0.6，x = 10 的概率为 0.4，求期望、方差和标准差。
  3. 两个分布的期望都是 5%，标准差分别为 1% 和 8%，对投资者意味着什么？
参考答案
  1. 概率之和为 1.10，不是 1；必须重新分配概率，不能直接使用这组数字。
  2. μ = 0.6×0 + 0.4×10 = 4；σ² = 0.6×(0-4)² + 0.4×(10-4)² = 9.6 + 14.4 = 24；σ = √24 ≈ 4.90。
  3. 相同期望下，后者波动更大，出现亏损和大幅回撤的风险更高；期望不描述风险，需要结合标准差、尾部损失和个人约束。
