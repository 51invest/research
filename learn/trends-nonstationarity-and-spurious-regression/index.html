趋势非平稳与伪回归

两个各自带趋势的非平稳序列可能产生很高的 R² 和显著斜率，即使它们彼此独立；水平回归的显著性必须与趋势、自相关和差分结果一起解读。

研究问题

数据由 scripts/simulate-spurious-regression.mjs 生成：种子 20261030 的那一次抽取列在正文，另有从 20261030 起连续 500 次独立抽取的分布；单次抽取只作示例，结论以分布为准。

数据

项目 数值
A 随机游走，月漂移 0.30，冲击 SD 1.00
B 随机游走，月漂移 0.25，冲击 SD 1.20
水平回归斜率 b 0.450（SE 0.022）
水平回归 R²（500 次抽取的中位数） 0.793
水平回归 R²（种子 20261030 单次抽取） 0.003
差分回归斜率 b 0.052（SE 0.124，种子 20261030 单抽）
差分回归 R²（中位数） 0.004
去趋势回归 R²（中位数） 0.091
残差 lag-1 自相关 0.963（种子 20261030 单抽）

A、B 为教学用的无量纲水平序列；漂移与冲击标准差均按每月计，回归斜率读作“每期 A 变化一单位对应的 B 变化”。

方法与假设

水平回归 B_t = a + b A_t + e_t 假设误差平稳、独立、同方差。若 A、B 含随机趋势（单位根），常规 t 分布不适用；两个独立趋势序列容易产生虚假显著关系，即伪回归（Granger & Newbold 1974）。诊断包括时间图、自相关、单位根检验，以及比较水平、差分和去趋势结果。差分回归 ΔB_t = a + b ΔA_t + e_t 去除随机趋势；若变量协整，水平回归才可能有意义。自相关可用于检测非随机性，随机性不成立时应改用时间序列模型（NIST 1.3.5.12）。

结果

先看单次抽取（种子 20261030）：水平回归 b = -0.069，SE = 0.120，t = -0.6，R² = 0.003，p = 0.57，残差 lag-1 自相关 0.963。这一对随机游走在这一回并没有造出漂亮的伪回归——单次抽取本就不可当证据。真正说明机制的是 500 次独立抽取的分布：水平回归 R² 的中位数为 0.793，5% 分位 0.226，95% 分位 0.938，有 83% 的抽取 R² 高于 0.5。两个序列按构造独立，高拟合来自各自的随机趋势在有限样本中呈现出的同向漂移，不是经济关系。

同一批 500 次抽取里，差分回归 R² 的中位数只有 0.004，95% 分位 0.031，没有一次抽取超过 0.5；本种子单次抽取为 b = 0.052，SE = 0.124，t = 0.4，R² = 0.001，p = 0.68，相关系数 0.04。差分去掉的是单位根，所以伪关系消失。去趋势则不同：本种子抽取给出 b = -0.945，SE = 0.087，t = -10.9，R² = 0.500，p = 0.00；500 次抽取的中位数是 0.091，95% 分位 0.491，仍有 5% 的抽取高于 0.5。原因是随机游走减去一条拟合直线之后仍是单位根过程，去趋势不会去掉单位根，这也正是它与趋势平稳情形的分界。

稳健性

  • 换种子或样本期，水平 R² 依旧常常很高（500 次抽取中 83% 高于 0.5），差分回归则从未高于 0.5；单个种子的数值不能当作结论，本例种子 20261030 的水平 R² 就只有 0.003。
  • 用对数差分（增长率）代替简单差分：b = 0.245，SE = 0.093，R² = 0.057——本种子的这一次抽取反而给出了看起来显著的负相关方向之外的结果，说明单抽的符号与大小都不稳定，应报告分布而非挑选种子。
  • 把时间趋势项直接放进水平回归，等价于这里的去趋势处理：随机游走去趋势后仍是单位根过程，500 次抽取的中位 R² 为 0.091、95% 分位 0.491，并不自动恢复“干净”的关系。
  • 若序列是趋势平稳而非单位根，去趋势后可能恢复关系；误判非平稳会过度差分。
  • 单位根检验功效低，不能仅凭一次检验断定；应结合经济含义和多个诊断。

局限

模拟展示的是机制，不是对任何真实序列的检验。真实数据有结构变化、季节性、测量误差和共同冲击；伪回归与真实共同趋势难以仅凭统计区分。本站的图表与数据快照展示的是共动与相关，属于关联证据，本文的教训同样适用于它们，不能据此得出因果或预测结论。高 R² 不是模型正确的证据，残差分析才能提供模型充分性的信息（NIST 4.4.4）。需要单位根或协整检验、稳健标准误和样本外验证。数值为模拟，不是真实数据。

结论强度

就机制而言，500 次独立抽取里水平回归 R² 的中位数为 0.793（83% 高于 0.5），而两个序列按构造独立；差分后中位数降到 0.004 且无一超过 0.5。本例种子 20261030 的单次抽取水平 R² 只有 0.003、去趋势后反而有 0.500，这恰好说明两件事：单抽不可当证据，而去趋势不会去掉单位根。因此，水平回归的显著性不能单独作为关系证据，必须处理趋势和非平稳，并按分布报告。这不是对真实市场的因果或预测结论。

知识点精读

趋势平稳

定义：趋势平稳是序列围绕确定性趋势波动、去除趋势后平稳；与单位根过程不同，冲击的影响是否永久消失是关键。

机制：趋势平稳序列可用去趋势回归，单位根需差分；错误处理会造成伪相关或过度差分。

例子：例如实际 GDP 常被建模为趋势平稳或含单位根，争论影响预测和因果。

边界：趋势平稳不是视觉判断；单位根检验功效低，结构断点会误判，趋势和随机漫步难区分，模型选择会影响长期预测。

差分

定义：差分是用当前值减前一期值，去除趋势和单位根，使序列更平稳。

机制：一阶差分得到变化量，季节差分去除季节模式；过度差分会引入负自相关和噪声。

例子：例如价格水平差分得到收益率，GDP 水平差分得到增长率。

边界：差分不是越多越好；它会丢失水平信息、放大噪声，单位根和趋势平稳处理不同，差分后模型解释也改变。

滞后

定义：滞后是把变量的过去值作为解释变量或工具，用于捕捉动态、预期和因果时点。

机制：滞后阶数由信息准则、理论和样本决定；滞后可处理自相关和反向因果，但也会引入遗漏和过度拟合。

例子：例如用过去季度投资预测当前 GDP，或用滞后政策变量识别效应。

边界：滞后不是因果证明；选择偏差、后视偏差和滞后长度操纵会影响结果，滞后变量也可能与其他因素相关，动态模型需稳定性检验。

协整

定义：协整是两个或多个非平稳序列的线性组合平稳，表示它们存在长期均衡关系。

机制：协整可用 Engle-Granger 或 Johansen 检验；误差修正模型同时刻画长期关系和短期调整。

例子：例如房价和收入可能各自趋势，但价租比或收入比存在长期均衡。

边界：协整不是任意相关；伪回归、结构断点和样本期会制造假协整，均衡关系也可能变化，交易策略还需考虑调整速度和成本。

季节性

定义：季节性是在固定周期（月、季、周）重复的模式，由天气、节日、生产周期和行为造成。

机制：季节模型用虚拟变量、傅里叶项、季节差分或分解；季节调整和季节预测需区分真实季节和一次性事件。

例子：例如零售在春节前上升、夏季用电高峰，是季节性。

边界：季节性不是固定规律；节日移动、气候和结构变化会改变模式，过度季节调整会消除真实信号，季节和周期也易混淆。

滚动分析

定义：滚动分析是在移动窗口上重复估计或回测，观察参数、收益和风险随时间的变化。

机制：窗口长度权衡稳定性与适应性；滚动回测可检测过拟合和 regime 变化，但会产生多重比较和边界效应。

例子：例如用 36 个月滚动窗口估计 beta，观察其漂移。

边界：滚动不是样本外证明；窗口选择影响结果，重叠窗口相关性高，滚动回测仍可数据窥探，结构断点会使历史窗口失效。

结构变化和波动

定义：结构变化是数据生成过程在某个时点发生持久改变，波动是方差随时间的聚集和变化。

机制：结构断点检验（Chow、Bai-Perron）和波动模型（ARCH/GARCH）用于识别；政策、技术和危机常造成断点。

例子：例如金融危机后波动率上升并持续聚集，监管改革改变市场结构。

边界：结构变化不是异常点；断点位置和数量难确定，波动聚集也可能由混杂造成，历史窗口在这些变化后不再代表未来。

数据与制度核对：趋势

把“趋势”放进真实数据之前，先核对四件事。第一是统计单位：来源报的是水平值、增长率、指数还是占比，分母是总产值、人口、劳动力还是金融资产；同一句话换掉分母就会得到不同结论。第二是时间口径：名义值与实际值、季调与非季调、财年与日历年不能直接拼接，涉及“非平稳”时尤其要写明基期和折算方法。

第三是制度边界。伪回归在来源国的法律、监管和会计规则下成立，换到另一套制度里，定义可能不覆盖同一批主体；跨境比较要先检查样本是否被同一规则约束。第四是反向核对：用另一个独立来源重算关键比例，至少让数量级、方向和单位对得上，再讨论因果。

这四步不能保证结论正确，但能挡住最常见的错误：把不同口径的两个数字相除、把短期波动当成长期趋势、把制度差异误写成行为差异。文章中的教学数字均为假设，正式引用时以来源原文的日期、单位和脚注为准。

边界条件与迁移练习：趋势

学习“趋势”最容易停在定义。真正要练的是把它和“非平稳”分开：前者回答哪个变量在动，后者回答这个变量通过什么渠道影响结果。两者经常同时出现，但一个描述状态，一个描述传导；把传导写成状态，就会把相关性误当因果。与“伪回归”的区别则在于层次：前者可以在单个主体上观察，后者要求一组共同规则约束同一批主体。三层混在一起，文章就会看起来什么都说了，实际什么都不能检验。

边界条件要写成可观察的门槛，而不是形容词。第一，样本门槛：数据是否覆盖完整周期，是否包含压力期，是否排除了退出市场的失败者。第二，单位门槛：水平值、增长率、比率和指数不能互换，分母必须明示。第三，制度门槛：规则生效日、适用主体和豁免条款是否一致。第四，行为门槛：当指标改变时，主体是否真的会调整决策，还是只是账面数字变化。四条中任何一条不成立，结论就只能作为情景，不能作为基准。

迁移练习的做法是换三个维度各问一次。换主体：从企业换到家庭，从银行换到基金，趋势的分子分母是否仍然成立？换时间：从季度换到年度，从正常期换到危机期，参数是否稳定？换制度：从一套监管换到另一套，非平稳的激励是否方向相反？三次换完，仍能复述同一条机制，才算掌握；一换就崩，说明原来记住的是案例，不是概念。

最后做一次自测：用 100 字解释“趋势”，必须包含一个单位、一个时间口径和一个反例；再用 100 字说明“非平稳”在什么条件下会失效。两段都写不出，就回到模块母文和同模块的另一篇主文，先把定义与口径对齐。模块深度不是字数，而是能否在换主体、换时间、换制度后仍给出可复核的判断。

复核题：趋势

  1. 用一句话说明“趋势”的分子、分母和单位，再说明它与“非平稳”不是同一个指标。
  2. 给出一个“伪回归”改变后结论翻转的例子，标明改变了哪条规则。
  3. 找一组跨期数据，说明季调、基期或修订如何改变方向。
  4. 设计一个换主体后的检验：从企业换到家庭，或从银行换到基金，哪些参数必须重估？
  5. 写一条可证伪判断：如果哪一个可观察信号出现，就应放弃本文结论？

练习

  1. 为什么两个独立趋势序列会得到显著斜率？
  2. 差分与去趋势有什么区别？
  3. 高 R² 为什么不能证明模型正确？
参考答案
  1. 两者都有随时间上升的趋势，水平回归把共同趋势误当成共同变化；残差高度自相关，常规标准误过小。
  2. 差分去除随机趋势，关注逐期变化；去趋势去除确定性时间趋势，保留水平信息。选择取决于趋势类型。
  3. R² 只衡量样本内拟合比例；残差自相关、异方差或遗漏变量都可能使高 R² 的模型无效。

  2. 把“趋势”与“非平稳”各写成一个可观察变量，并指出二者的时间差。
  3. 给“伪回归”找一个规则变化，说明它如何改变样本覆盖。
  4. 用本文的方法做一次反事实：只改变一个变量，其他条件保持不变。
  5. 如果换一个独立来源，哪一个数量级最可能变化？为什么？
  6. 写一条可证伪判断，包含观察信号、等待时间和复核指标。
