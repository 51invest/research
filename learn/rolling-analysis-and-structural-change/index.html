滚动分析与结构变化

前半段估到 0.54、后半段 0.20 时，全样本斜率 0.34 会掩盖断点；滚动路径、断点检验和样本外预测必须一起报告，并说明窗口与断点如何选择——检验不显著也可能只是功效不足。

研究问题

一个假设关系中，前 60 个月的斜率为 0.60，后 60 个月为 0.10。全样本回归、滚动窗口和断点检验会分别给出什么？本文用 120 个月模拟数据说明滚动分析与结构变化。数据由种子 20261031 生成，不是真实数据。

数据

项目 数值
样本 120 个月
频率 月度
生成斜率 第 1–60 月 0.60；第 61–120 月 0.10
全样本回归 b = 0.34（SE 0.07），R² = 0.16，r = 0.40
前 60 月 b = 0.54（SE 0.11），R² = 0.30，r = 0.54
后 60 月 b = 0.20（SE 0.09），R² = 0.07，r = 0.27
24 个月滚动相关 97 个窗口，范围 -0.19 至 0.71
24 个月滚动斜率 范围 -0.15 至 0.83
已知断点 F 检验 F(2,116) = 2.8，p = 0.065（5% 水平不拒绝）
前 60 月外推后 60 月 样本外 R² = -0.13（基准为训练期均值）
许可 模拟数据，无外部许可

记号 N(μ,σ) 的第二参数是标准差而不是方差（本模型依次取 1、0.5 与 1）。x、y 是教学模拟的月度序列，单位为任意模拟单位（无量纲）；斜率读作“x 每变化 1 个单位对应的 y 变化”，滚动统计在 120 个月样本上按 24 个月窗口计算。

方法与假设

滚动分析在每个时点用最近 W 期重估参数，得到系数或相关系数路径；窗口越短越能捕捉变化，但噪声也越大。结构变化指参数在某个时点改变。断点已知时，可比较合并样本与两个子样本的残差平方和，构造 F 统计量；无约束模型有两个截距和两个斜率，所以分子自由度为 2、分母自由度为 120 − 4 = 116。断点未知时，Andrews（1993）对每个候选断点计算统计量并取上确界，分布非标准。R² 不能替代模型验证，残差图可显示漂移和非恒定方差（NIST 4.4.4）。

结果

全样本斜率 0.34，看似中等正关系。分段后前 60 月为 0.54、后 60 月为 0.20，后一段明显变弱，但估计仍高于设计真值 0.10；已知断点的 F(2,116) = 2.8，p = 0.065，在 5% 水平不能拒绝参数不变，在 10% 水平可以。24 个月滚动相关在 -0.19 至 0.71 之间，滚动斜率在 -0.15 至 0.83 之间；只报告 0.71 的那个窗口会同时夸大关系的强度和稳定性。用前 60 月模型预测后 60 月，样本外 R² = -0.13（基准为训练期均值），比直接用均值更差。上面全部数值由 npm run sim:rolling-structure 用种子 20261031 实跑得到，npm run check:sim 会把正文与脚本输出逐项比对。把种子换成从 20261031 起的 400 个连续值重跑：全样本斜率均值 0.35、95% 区间 0.18–0.51；F 统计量均值 6.71、区间 0.88–15.54；样本外 R² 均值 -0.38、区间 -1.19–0.11。本实现落在偏低端，说明 60+60 个月、噪声与断点幅度同量级时断点检验有功效但并不稳定——检验不显著不等于结构没有变化。

稳健性

  • 窗口改为 18 或 36 个月，路径更抖或更平滑，但断点后系数同样下移。
  • 用稳健标准误或秩相关，分段差异仍在，具体数值会变。
  • 断点未知时用 sup 检验，已知时用 F 检验；若断点由数据窥探选出，临界值需相应校正。
  • 检查子时期是否由少数观测驱动，并报告所有窗口长度和断点选择方式。

局限

模拟断点是外生、突变的；真实结构变化可能渐进、多次，或与波动率变化同时出现。滚动窗口有端点效应，窗口长度和断点日期都会影响结论。断点检测不解释原因，不能把统计断点直接当作政策或制度变化。向样本外时期外推属于超出观测范围（OpenStax 12.5）。

复现

  1. 用固定种子 20261031 生成 120 个月的 x 和两段斜率（npm run sim:rolling-structure）。
  2. 估计全样本与两个子样本回归。
  3. 计算 24 个月滚动相关与滚动斜率。
  4. 做已知断点 F 检验，并用前 60 月预测后 60 月。
  5. 报告窗口长度、断点选择方式和所有子时期。
seed = 20261031
lvl[0] = 0
lvl[t] = 0.5*lvl[t-1] + N(0,1)
x[t] = lvl[t] + N(0,0.5)
b = 0.60 (t <= 60), 0.10 (t > 60)
y[t] = 0.2 + b*x[t] + N(0,1)
rolling window = 24
F test, break = 60, df = (2,116)
每月抽样顺序：先 lvl innovations，再 x 噪声，最后 y 噪声

结论强度

模拟中参数确实改变（设计值为 0.60 与 0.10）：全样本系数混合了两段，滚动路径显示不稳定，样本外预测失败；而本实现的 F 检验没能在 5% 水平拒绝参数不变，这是功效不足，不是结构不变的证据。这些是描述性结论；真实数据中的断点需结合制度信息，不能仅凭统计结果断言因果。

工作纸：把判断拆成可复核的四栏

本文的主题是“RES-018”。读完之后，不要先记结论，先做一张四栏工作纸：第一栏写“滚动窗口”的定义、分子、分母和单位；第二栏写“结构变化”的传导渠道；第三栏写“参数不稳定”的制度边界；第四栏写结论的反证信号。四栏都填满，才允许把结论带进下一步；任何一栏空白，结论就只能当作假设。

第一栏最容易偷懒。把指标写成一句“越高越好”，等于没有定义。至少要回答：它衡量的是存量还是流量，分母是产出、人口、资产还是交易量，价格是名义还是实际，时间点是期末还是期间平均。换掉其中任何一个，排序和结论都可能改变。若来源只给了一个数字而没有给出分母，先回到来源脚注，不要用相邻文章的分母替代。

第二栏要把“结构变化”写成一条可观察的链：哪一个变量先动，经过什么中介，最后改变哪个结果。链上每一环都要有时间和单位，不能把“长期”与“季度”混写。链越长，越要标出哪一环是作者推演、哪一环有来源支持；推演可以用于教学，但不能冒充事实。

第三栏处理制度。参数不稳定不是背景段落，而是样本定义：哪些主体被覆盖，哪些被豁免，规则从哪一天生效，跨境比较是否由同一套规则约束。制度不同，同样的数字会对应不同的激励；把制度差异写成行为差异，是跨市场比较里最常见的错误。若无法确认规则一致，就把比较降级为“两个独立情景”，不要给出排序。

第四栏写反证。用一句可证伪的话收尾：“如果观察到 A，在 B 时间内出现 C，则原判断成立；否则放弃。”A 必须是可观察的变量，B 必须是可以等待的时间，C 必须是可以复核的结果。三项写不清，说明结论还不可检验。最后把工作纸、来源链接和复核日期放在同一页；下一次复盘时，先看当时的四栏，而不是只看事后结果。

记录模板

把四栏压缩成一页：左栏写口径与单位，中栏写机制与制度，右栏写反证与复核日期。数据更新时只改数字，不改结论文字；若结论文字必须改，说明口径或制度变了，回到来源重做检查。记录里保留一栏反方意见，下一次复盘先问证据是否推翻了反方，再问仓位是否赚钱。

边界算例：全样本 0.34，前后两段 0.54/0.20，断点在哪里

设 120 个月，前 60 月斜率 0.54、后 60 月 0.20，全样本 0.34；已知断点 F(2,116)=2.8、p=0.065，5% 水平不拒绝，10% 水平拒绝。24 个月滚动斜率在 -0.15 到 0.83 之间，若只挑 0.83 的窗口，会夸大强度和稳定性。若窗口缩到 12 个月，滚动范围更宽，假信号更多；若窗口拉到 36 个月，断点被平滑，可能看不见。

反转条件是“断点日期由数据挑选”：先看结果再选断点，p 值不再有效；预注册断点或使用 sup-F 检验更可靠。边界在于，滚动分析描述路径，断点检验判断参数是否变，样本外检验判断预测是否可用；三者回答不同问题。

以上数字来自本文模拟设定，不是市场数据。

延伸判读

滚动窗口检验的是“关系是否随时间稳定”，不是“模型能否永远预测”。窗口太短，参数被噪声主导；窗口太长，结构变化被平均掉。要看滚动系数路径、样本外误差和断点检验：系数若在某次政策或危机后持续改变，说明旧模型失效；若只是短期跳动，可能仍在正常范围。报告窗口长度、重估频率和交易成本，才能判断结果是否可实施。 上述制度与定义可对照公开资料 [4]；例子中的数字均为教学假设。
