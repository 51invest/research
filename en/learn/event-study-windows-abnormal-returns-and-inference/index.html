Event Studies: Windows, Abnormal Returns and Inference

An event study subtracts model-expected return from realised return in an event window to obtain abnormal return; window choice and inference determine credibility.

Definition

An event study measures the effect of an event on firm value. The estimation window uses pre-event dates unaffected by the event to estimate a normal-return model; the event window covers dates around the event used to calculate abnormal returns. Abnormal return (AR) is realised return minus model-expected return; cumulative abnormal return (CAR) sums AR over the window. The market model is commonly R_i = α + β R_m + ε, with α and β estimated in the estimation window [1].

Intuition

An event study is like comparing medical tests before and after surgery: to judge whether a treatment worked, you need the pre-period trend, changes in other patients over the same period and measurement error. Abnormal return is the return in the event window after subtracting normal market-related movement. The estimation window is the pre-period baseline, the event window is the post-period observation, and the test statistic asks whether the abnormal return is a real effect or noise. A wider window captures more but also admits other news; a narrower window may miss delayed reactions.

Mechanism

The steps are: define the event and event date, choose estimation and event windows, estimate the normal-return model, compute AR and CAR, then run cross-sectional or time-series tests. The event date must come from a public, verifiable timestamp or the study looks ahead. A longer window captures delayed reaction but also absorbs other news. Thin trading makes closing prices stale and smooths AR; overlapping events make firm ARs correlated, so a plain t-test understates standard errors. Model misspecification, non-normal returns and volatility shifts also need treatment [2][3].

Worked example

Suppose the estimation window gives α = 0.0 and β = 1.2, the market return on the event day is 1.0%, and the firm returns 3.2%. Expected return is 1.2%, so AR = 3.2% − 1.2% = 2.0%. If the next two days' AR are 1.5% and −0.5%, the three-day CAR is 2.0% + 1.5% − 0.5% = 3.0%. If the estimation residual standard deviation is 1.5%, the t-statistic for a 2.0% one-day AR is about 1.33, not significant at conventional thresholds; CAR significance must also account for event-window correlation. These are teaching assumptions and exclude trading costs and cross-sectional correlation.

Second worked example: market model and significance

Suppose a 120-day estimation window gives a market model with α = 0.001 and β = 1.2. On the event day the market returns 2.0% and the stock returns 3.0%; expected return = 0.001 + 1.2 × 0.02 = 0.025, so abnormal return = 0.03 − 0.025 = 0.005, or 0.5%. If the standard deviation of abnormal returns is 1.5%, the one-day t-statistic is 0.5%/1.5% = 0.33, far below the usual 1.96 threshold, so 'no abnormal return' cannot be rejected. If the three-day cumulative abnormal return is 1.5% and the standard deviation scales by √3 to 2.6%, the t-statistic is about 0.58, still insignificant. Only by combining residual volatility, event clustering and cross-sectional correlation can you judge whether 0.5% is economically meaningful or statistically noise. These are teaching assumptions.

Boundary and common mistakes

First, an event date that is not the announcement date can look ahead; after-close announcements should shift to the next trading day. Second, abnormal return is not causal proof; the event may coincide with other news. Third, CAR cannot be tested with a one-day t-test after simply summing daily AR; event-window correlation and volatility changes matter. Fourth, thin trading and suspensions prevent prices from reflecting information promptly. Fifth, with small samples or highly overlapping events, use robust standard errors or permutation tests.

Failure modes

The first failure is event-date misalignment: an announcement after the close is counted on the same day; the first tradable reaction day should be day 0. The second is confounding events: earnings, M&A or industry policy inside the same window make the abnormal return unattributable to one event. The third is thin trading and suspensions: prices do not update continuously, distorting beta and abnormal returns. The fourth is event clustering: several firms in one industry have events on the same day, and cross-sectional correlation inflates t-statistics; use clustered standard errors or a portfolio method. The fifth is multiple testing: trying many windows and models and reporting only the most significant one is data mining.

Three checks

First, is the event date defined by the first tradable reaction, and is the estimation window clean of event-period contamination? Second, what is the abnormal-return model, are alpha, beta, residual volatility and benchmark stated, and has thin trading been checked? Third, are statistical significance and economic meaning separated, and are clustering, multiple testing and cross-sectional correlation handled? Only then does a 0.5% abnormal return become interpretable.

Adjacent concepts and a counterexample

Event studies are easily confused with case studies and natural experiments. A case study describes the mechanism and context of one event without estimating an average effect; a natural experiment uses an exogenous shock with treatment and control groups to identify causality; an event study estimates abnormal returns in an event window, focusing on the expected-return model and inference. Identification assumptions differ. A counterexample is 'a significant abnormal return means the event worked': if the event date overlaps earnings, policy or industry news, the return cannot be attributed to one event; with a single firm, significance can be noise. Another is 'a longer window is more comprehensive': a longer window admits more confounding news and lowers precision; pre-register the window and model to avoid post-hoc selection. Compare event studies on event-date definition, estimation window, benchmark model and robustness.

Scope and limits

This event-study framework applies to public-market research with precisely identifiable event dates, estimable expected-return models and sufficient cross-sectional samples. If the event date is ambiguous, the sample is one firm, or the event overlaps industry shocks, attribution and significance weaken. It does not apply to treating short-window abnormal returns as long-run causality, nor to ignoring trading costs and liquidity. Define the event date, estimation window and benchmark model, then run placebo, subsample and cost adjustments; significance is not economic magnitude.

Finally, if the event window spans several trading days, treat weekend, holiday and suspension drift separately; cross-market samples must also align time zones and currencies, or summed abnormal returns are not comparable.

If sample firms span industries, neutralise by industry; events close in calendar time should be clustered, or standard errors are understated, and report economic magnitude, not only t-statistics.

Also keep reproducible intermediate records and scripts.

Working paper: four columns for a checkable judgement

The subject of this article is "Event study: windows, abnormal returns and inference". Do not begin by memorising a conclusion; begin with a four-column worksheet. Column one states the definition, numerator, denominator and unit of "Estimation and event windows". Column two states the transmission channel of "Abnormal and cumulative returns". Column three states the institutional boundary of "Inference, contamination and overlapping events". Column four states the signal that would refute the conclusion. Only when all four are filled may the conclusion travel to the next step; an empty column turns it into an assumption.

Column one is where shortcuts appear. Writing "higher is better" is not a definition. At minimum, answer whether the metric is a stock or a flow, whether the denominator is output, population, assets or transaction volume, whether the price is nominal or real, and whether the observation is an endpoint or a period average. Change any one and the ranking or conclusion can move. If a source gives a number without a denominator, return to its footnote rather than borrowing the denominator from a neighbouring article.

Column two turns "Abnormal and cumulative returns" into an observable chain: which variable moves first, through which intermediary, and which outcome changes last. Every link needs a time and a unit; do not mix "long run" with "quarterly". The longer the chain, the more important it is to mark which link is the author's inference and which link has source support. Inference may teach, but it may not masquerade as fact.

Column three handles institutions. Inference, contamination and overlapping events is not background colour; it is the sample definition. Which entities are covered, which are exempt, when does the rule take effect, and does a cross-border comparison bind the same sample to one rule? Different institutions attach different incentives to the same number. Writing an institutional difference as a behavioural difference is the most common error in cross-market comparison. If the rules cannot be aligned, downgrade the comparison to two separate scenarios and do not rank them.

Column four writes the refutation. End with a falsifiable sentence: "If A is observed and C follows within B, the claim holds; otherwise it fails." A must be observable, B must be a waitable period, and C must be a checkable result. If the three cannot be written, the claim is not testable yet. Research question

An event study asks whether abnormal returns around an event differ significantly from normal returns. The normal-return model, event window, estimation window and inference method must be fixed in advance.

Data

Event dates, announcement times, prices and returns, benchmark or market factors, suspensions and missing records, and sample filters. Distinguish announcement date, effective date and first tradable time.

Method

Estimate normal returns with a market or factor model, subtract them from actual returns in the event window to get abnormal returns, aggregate across events, and report statistical and economic significance.

Results

Report abnormal return, cumulative abnormal return, cross-sectional distribution, sample size and confidence intervals together. Significance is not causation; other news in the window may explain the result.

Robustness and limitations

Change estimation windows, benchmarks, event-date definitions, exclude overlapping events and outliers, and check stability. If the result holds only in one window, state a conditional finding.

Reproduction checklist

Keep the event list, date sources, return data, model parameters, window definitions and inference code; rerun on another sample or market.
